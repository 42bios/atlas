# Changelog

## 0.1.0-alpha.1 — 2026-10-29

First public alpha of Atlas.

- Connected inventory for racks, devices, interfaces, IP planning, cables, power and applications.
- Front/rear rack views, free-space placement, shelves and device model catalogs.
- Application hosting/dependency maps and topology observations.
- GitHub-backed Marketplace with pinned READMEs and explicit package review.
- Isolated connector execution and protected backup/restore tools.
- English handbook, REST API documentation and Light/Dark/Auto appearance.
- Corrected first-install data-directory ownership and clarified Linux Docker prerequisites.
- Publication excludes private inventories, credentials and local audit/deployment evidence.
- GPL-3.0-only code license. Manufacturer picture library excluded from the default offering pending permissions.

See [known limitations](KNOWN_LIMITATIONS.md) for live-adapter and platform validation boundaries.
