# Contributing to Atlas

Open an issue describing a reproducible problem or proposed improvement before a substantial change. Small fixes and documentation improvements are welcome.

Use fictional fixtures and documentation IP ranges. Never include controller credentials, access tokens, private inventories, production screenshots or backup archives in a contribution.

Run the Python and JavaScript tests from the README. Test data mutations in a disposable database. Frontend changes must be verified through the assembled plugin contexts and relevant browser flows. Describe the problem, resulting behavior, tests and known limits in a pull request.

Keep the UI and documentation in English. Update the handbook and generated API/binding declarations when their contracts change. Avoid introducing monitoring behavior or enterprise management scope without discussing the product direction.

Contributions to this repository are under GPL-3.0-only, the same license as Atlas. Do not add third-party assets unless their source, license and redistribution permission are recorded. Connector add-ins belong in separate repositories.
